# Exploding Kittens - Modern Frontend

A premium, interactive, and fully functional frontend for an Exploding Kittens-inspired multiplayer card game.

## 🚀 Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS (Custom Dark Theme)
- **Animations:** Framer Motion
- **State Management:** Zustand
- **Icons:** Lucide React
- **Effects:** Canvas Confetti

## ✨ Features
- **Turn-based Logic:** Fully simulated multiplayer turn system with AI bots.
- **Card Interactions:** Play Attack, Skip, Shuffle, See the Future, and Defuse.
- **Smooth Animations:** Cinematic card draws, plays, and danger shakes.
- **Premium UI:** Minimalist dark mode design inspired by Linear and Apple.
- **Responsive Layout:** Adaptive board for desktop and mobile play.

## 🕹️ How to Play
1. Click **Start Game** in the lobby.
2. On your turn, you can either **Play a Card** from your hand or **Draw a Card** from the deck.
3. Drawing a card ends your turn.
4. If you draw an **Exploding Kitten**, you lose immediately unless you have a **Defuse** card.
5. Use power cards (Attack, Skip, etc.) to avoid drawing or to sabotage opponents.
6. The last player standing wins!
